# Getting help

| I want to... | Go to |
|---|---|
| install or run AstraX | [docs/INSTALLATION.md](docs/INSTALLATION.md) and [docs/QUICKSTART.md](docs/QUICKSTART.md) |
| learn how to use it | [docs/USER_GUIDE.md](docs/USER_GUIDE.md), [docs/TUTORIALS.md](docs/TUTORIALS.md) |
| fix an error or lag | [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md), [docs/FAQ.md](docs/FAQ.md) |
| ask a question | GitHub **Discussions** (Q&A) |
| report a bug | a **Bug report** issue (run `python main.py --diagnostics` first and attach the result) |
| suggest a feature | a **Feature request** issue |
| report a security problem | [SECURITY.md](SECURITY.md) (private) |
| contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

Maintainers are volunteers; please be patient and kind ([Code of Conduct](CODE_OF_CONDUCT.md)).
