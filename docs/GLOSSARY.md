# Glossary

| Term | Meaning |
|---|---|
| **Abort** | emergency action: stages jettisoned, payload capsule escapes and lands on a parachute |
| **Angle of attack (α)** | angle between the rocket's axis and the oncoming air |
| **Apogee / Apoapsis** | highest point of an orbit |
| **Perigee / Periapsis** | lowest point of an orbit |
| **Ballistic coefficient** | mass / (Cd × area); higher = slows less in air |
| **C3** | characteristic energy = v∞² (km²/s²) |
| **CoM / CoP** | centre of mass / centre of pressure (CoP below CoM = stable) |
| **Cd** | drag coefficient |
| **Delta-v (Δv)** | total change in speed a rocket can produce |
| **Dynamic pressure (q)** | ½ρv², the aerodynamic load; peak value is **max-Q** |
| **Eccentricity (e)** | orbit shape: 0 circle, <1 ellipse, 1 parabola, >1 hyperbola |
| **Gravity turn** | ascent where the rocket follows its velocity, gravity bends the path |
| **Hohmann transfer** | two-burn minimum-energy transfer between circular orbits |
| **Inclination** | tilt of an orbit relative to the reference plane |
| **Isp** | specific impulse (s): engine efficiency |
| **Lambert problem** | find the orbit connecting two positions in a given time |
| **LEO** | low Earth orbit (~200–2000 km) |
| **Mach number** | speed ÷ speed of sound |
| **Mass ratio** | initial mass ÷ final mass |
| **Max-Q** | moment of peak dynamic pressure |
| **MET** | mission elapsed time |
| **N-body** | gravity between all bodies, not just one central body |
| **Osculating orbit** | the two-body orbit that matches the current position and velocity |
| **Porkchop plot** | map of transfer cost vs departure date and flight time |
| **Prograde / Retrograde** | along / against the velocity |
| **Radial / Normal** | toward-away from the body / perpendicular to the orbit plane |
| **Static margin** | (CoM − CoP)/diameter in calibres; positive = stable |
| **Suicide burn** | landing burn started as late as possible to stop exactly at the ground |
| **Synodic period** | time between repeating alignments of two planets (Earth–Mars ≈ 780 d) |
| **T/W** | thrust-to-weight ratio (>1 needed to lift off) |
| **TVC** | thrust-vector control (engine gimbal) |
| **v∞ (v-infinity)** | speed relative to a planet after escaping its gravity |
| **Yield** | stress at which metal permanently deforms (failure criterion here) |
