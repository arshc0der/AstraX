## `astrax.aero`

Aerodynamics, heating and structural-load models (SIMPLIFIED, documented in docs/PHYSICS.md). * speed of sound a = sqrt(gamma R T); Mach M = v_air / a. Earth T(h): US Standard Atmosphere 1976 layers. * Drag coefficient Cd(M) = Cd_ref * f(M): a generic transonic-peak shape (subsonic -> rise -> peak near M~1.1 -> decay). This is a textbook-shaped curve, NOT wind-tunnel data for any vehicle. * Normal force N = q A CNalpha sin(alpha) cos(alpha); CNalpha from a simplified Barrowman model (rocket.cn_alpha()). * Stagnation-point convective heating, Sutton-Graves: q_dot = k sqrt(rho / R_nose) v^3 [W/m^2]. * Shell stress at a stage base: sigma = N/(2 pi R t) + M/(pi R^2 t) (thin-walled tube; no buckling, no fatigue).

## `astrax.atmosphere`

Atmospheric density models. Earth: tabulated US Standard Atmosphere 1976 densities, log-linear interpolation (0-150 km), zero above. Other bodies: single-scale-height exponential rho = rho0 * exp(-h/H) up to the stated top altitude. Simplified: no weather, no solar-activity dependence, no temperature/Mach modelling.

### `density(body, altitude_m: 'float') -> 'float'`



### `pressure(body, altitude_m: 'float') -> 'float'`

## `astrax.bodies`

Celestial body reference data + editable runtime copies. REFERENCE DATA (never silently modified - the editable copy is separate): * GM values: JPL Solar System Dynamics, "Planetary Physical Parameters" (ssd.jpl.nasa.gov/planets/phys_par.html); IAU 2015 nominal values for the Sun. * Mean radii: same JPL table / IAU WGCCRE 2015 report. * Orbital elements: E. M. Standish, "Keplerian Elements for Approximate Positions of the Major Planets" (JPL), Table 1, valid 1800-2050 AD, epoch J2000.0, ecliptic/equinox J2000. * Moon elements: approximate osculating J2000 values (Meeus, Astronomical Algorithms). LIMITATIONS: mean elements are NOT an ephemeris (errors of arcminutes to a few arcminutes for inner planets, more for outer planets). Rotation poles are simplified: the spin axis is the ecliptic north tilted by the axial tilt about the +X axis. PLEASE verify the numbers against the cited tables before publishing results.

## `astrax.simulation`

Headless simulation engine (no Qt / OpenGL imports). Everything physical lives here. Model summary (documented assumptions - see docs/PHYSICS.md): * N-body Newtonian gravity between all bodies (point masses, softening none). The rocket is a test particle: it feels every body's gravity but does not perturb them. * Variable mass: dm/dt = -F_vac / (Isp_vac * g0) per active engine group, exact over a step. * Thrust varies with ambient pressure: F = mdot * g0 * Isp(p), Isp(p) linear between vac and sea level. * Drag: F = 0.5 rho Cd A |v_air|^2 along -v_air; air co-rotates with the body. Lift not modelled. * Guidance (direction) and throttle are held constant over each integration step (zero-order hold). * Frame: barycentric ecliptic J2000 inertial; spin axes simplified (see bodies.py). Integrators: 'rk4' (fixed), 'dopri5' (adaptive RK 5(4)), 'verlet' (velocity Verlet, symplectic).

## `astrax.survival`

Design survival test: fly the rocket through a standard ascent and report whether it survives. Runs headless (no UI). The standard profile is `missions.earth_leo`; for each trial pitch-kick angle the full ascent is simulated (Mach-dependent aerodynamics, loads, structural/thermal checks, protective throttling). The best trial is reported, then an orbit-persistence check coasts a few orbits. A failure may reflect the generic guidance profile rather than the design - the report says so. This is a SCREENING tool, not certification.
