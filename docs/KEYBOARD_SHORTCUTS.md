# Keyboard and mouse reference

## Keyboard
| Key | Action |
|---|---|
| `Space` | Run / pause |
| `N` | Single physics step (while paused) |
| `R` | Reset to launch conditions |
| `S` | Stage (manual separation) |
| `+` / `-` | Faster / slower time acceleration |
| `F` | Focus on the selected body |
| `Home` | Reset camera |

## 3D view mouse
| Mouse | Action |
|---|---|
| Left-drag | rotate the camera |
| Middle-drag (or Shift + left-drag) | pan |
| Wheel | zoom |
| Right-drag | zoom |
| Double-click an Explorer item | focus on it / open its inspector |

(Launch camera and First-person mode control the camera automatically; switch to *Orbit* or *Free* to steer manually.)

## Graphs (pyqtgraph)
| Mouse | Action |
|---|---|
| Left-drag | pan |
| Wheel | zoom both axes |
| Right-drag | scale axes independently |
| Right-click | menu: auto-range, export image/CSV, grid, log scale |

## Windows
`Alt+Tab` to switch windows; drag a dock title to float, tab or re-dock it.
